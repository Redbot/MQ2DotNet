# /netend

## Syntax

<!--cmd-syntax-start-->
```eqcommand
/netend *
/netend myprogram
```
<!--cmd-syntax-end-->

## Description

<!--cmd-desc-start-->
This will stop all programs you have started using /netrun. You can also stop just one with: `/netend myprogram`
<!--cmd-desc-end-->

If you want to stop if halfway through, you can:

```csharp
/netend *
```

This will stop all programs you have started using /netrun. Did I mention you can run as many as you want at the same time? You can also stop just one with:

```csharp
/netend myprogram
```
